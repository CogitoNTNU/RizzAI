# RizzAI Frontend

A React-based web application for generating AI-powered opening lines based on profile images and descriptions.

## Features

- 📸 Image upload with drag-and-drop support
- ✍️ Profile description input
- 🤖 AI-powered opening line generation (3 variations with different parameters)
- 💋 Animated kiss celebration when selecting the best line
- 🎨 Beautiful gradient UI with Tailwind CSS

## Setup

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm start
```

The app will open at [http://localhost:3000](http://localhost:3000).

## Prerequisites

Make sure the backend API server is running at `http://localhost:8000`. See the `backend` directory for setup instructions.

## Tech Stack

- React 18
- Tailwind CSS
- Fetch API for backend communication
